Campo de mensagem: textarea de uma linha que cresce até 144px, mais o botão de enviar.

O botão `cacic-send` fica desativado enquanto o campo está vazio e durante o envio; ativo, usa `--gradient-send` com anel `ink`, como o botão circular das artes. Enter envia e Shift+Enter quebra linha. O consumidor fornece o placeholder (uma sugestão de tema), o rótulo acessível "Sua pergunta" e o aviso `cacic-note` logo abaixo.

- Faça: manter o campo sempre visível no rodapé da página.
- Evite: placeholder longo no celular; trocar o ícone de enviar por avião de papel.
